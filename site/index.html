Q-TDE GitHub ↗

Inspect the code. Understand the risk.

Q-TDE examines a QR image on two independent axes: whether the code was altered, and how its URL is constructed.

Open the inspector ↗

The inspector is a Streamlit app hosted on Streamlit Community Cloud. This page is hosted on Vercel and only links to it. The app may take a short while to wake if it has been idle.

Two questions, answered separately

Physical integrity

Reed-Solomon syndrome checks for Version 3-M symbols, plus a high-frequency residual compared against a calibrated threshold.

URL structure

21 weighted static rules over the decoded payload. Nothing is fetched, resolved or executed.

Known limitations

ECC coverage
Reed-Solomon analysis supports Version 3-M only. Other versions are reported as unsupported geometry.
Calibration
The residual threshold was calibrated on synthetic renders; photographs can shift it either way.
No verdicts
No evidence detected is not proof a code is genuine, and a URL score is a heuristic, not a probability of harm.
Camera
Use the browser camera or upload an image. Server webcam capture is not available on a hosted deployment.
